# CampusTareas web

Agenda para estudiantes que consultan y crean entregas. La API y sus campos son la fuente de datos; no hay datos de demostración ni almacenamiento simulado en el navegador.

Interfaz de operación: formulario lateral y lista con filtros, apilados en móvil. Azul académico #234ac3, tinta #172c48, texto secundario #53647a, fondo #f2f5fa y papel #ffffff. Tipografía Segoe UI disponible localmente en Windows; títulos compactos, cuerpo legible. Filas de tareas con casillas nativas, fechas y descripción. Estados de carga, error y lista vacía explícitos. El frontend usa el mismo origen que la API y no necesita CORS.
